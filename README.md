# Unitary Optimization Does Not Restore Superadditivity of Quantum Relative Entropy

**Author:** Ao-Xiang Liu

**Manuscript date:** August 2, 2026

Research manuscript presenting an explicit counterexample to unitary-optimized superadditivity of quantum relative entropy, with extensions to arbitrary bipartite dimensions.

- [Read the manuscript (PDF)](relative_entropy_unitary_superadditivity_counterexample.pdf)
- [LaTeX source](relative_entropy_unitary_superadditivity_counterexample.tex)

## Build

With a TeX distribution containing REVTeX 4.2 and `latexmk`, run:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error relative_entropy_unitary_superadditivity_counterexample.tex
```

The bibliography is included in the LaTeX source.
